WHAT'S INCLUDED
- Installable PWA for Android Chrome
- Home-screen app icon
- Standalone app-like display
- Offline caching for the web app shell
- Product image upload via Camera/Gallery
- Products, stock, POS/sales, customers, expenses, reports
- Local data storage
- Backup and Restore

HOW TO INSTALL ON ANDROID
1. Extract this ZIP on a device or web host that serves files over HTTPS.
2. Open the app URL in Google Chrome.
3. Open Chrome menu (⋮).
4. Tap "Add to Home screen" or "Install app" when available.
5. Open IBSAA MANAGER from the new home-screen icon.

IMPORTANT
- PWA installation normally requires HTTPS (or localhost). Opening index.html directly from a file manager may show the web app but may not allow service-worker installation.
- Data is stored locally in the browser/device. Use Backup regularly.
- Clearing browser/app data can remove locally stored business data.
